SGA MDS - PROYECTO LISTO PARA GITHUB
====================================

1) NO SUBAS ESTE ZIP DIRECTAMENTE A GITHUB.
2) EXTRAE EL ZIP COMPLETO.
3) ABRE LA CARPETA SGA_MDS_GitHub_Ready.
4) COMPRUEBA QUE VES: .github, app, gradle, docs y sample.
5) SUBE TODA ESA CARPETA CON GitHub Desktop o ejecuta SUBIR_A_GITHUB.bat.

PARA GENERAR EL APK:
- GitHub -> Actions -> Build Android APK -> Run workflow.
- Al finalizar descarga el artefacto SGA-MDS-debug-apk.
